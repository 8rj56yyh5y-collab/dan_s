# БХ Учёт

Система учёта для подразделения **БХ**: заявки на закупку, деньги под отчёт, чеки, доходы и аналитика.
Каждая потраченная гривна проходит путь **заявка → согласование → покупка → отчёт с чеком → проведено**,
и руководитель видит всё: затраты, прибыль, кто сколько и почём покупает.

Дизайн и устройство — как у Gobsek / Gobsek Seller: шрифт Onest, три темы (светлая, тёмная, эко),
боковое меню на компьютере и нижнее меню с кнопкой «+» на телефоне, ставится на экран «Домой» как приложение.

## Два кабинета

**Сотрудник** (инженер, мастер…) видит только свои записи:
- **Заявка на покупку** — наименование, количество, единица, цена, и для онлайн-покупки обязательно ссылка на товар.
  Для покупки в магазине — примерная цена и магазин.
- **Деньги под отчёт** — запросить сумму, после покупки отчитаться позициями и чеками, вернуть остаток.
- **Отчёт** — цены и количество по чеку + фото/PDF чека. Без чека отчёт не принимается.
- **Доходы** — что продали, кому, сколько, каким способом оплаты, с документом.
- **2 часа на исправление** ошибок после отправки. Дальше — только через «Запрос на корректировку» руководителю.

**Руководитель** видит всё и принимает решения:
- **Обзор** — доходы, расходы, прибыль за месяц, что ждёт решения (заявки, отчёты, доходы, корректировки).
- **Заявки** — согласовать (можно меньшую сумму), вернуть на доработку, отклонить, отметить выдачу денег, провести отчёт.
- **Аналитика** — любой период со сравнением с прошлым, график доходов/расходов за 12 месяцев,
  прибыль по объектам и заказам, расходы по категориям и сотрудникам (план vs факт), самые затратные позиции,
  онлайн vs офлайн, деньги под отчётом, выгрузка в CSV.
- **Контроль** — автоматическая проверка каждой заявки:
  - цена за единицу выше обычной (медиана прошлых покупок того же товара) больше чем на 15 %;
  - потрачено больше согласованного; цена по чеку выше цены в заявке;
  - нет чека; **один и тот же чек приложен к двум заявкам**;
  - ИИ прочитал в чеке другую сумму, чем указано в отчёте;
  - заявку меняли после согласования; отчёт правили после отправки; деньги выданы > 7 дней назад без отчёта.
  - **Контроль цен**: по каждому товару — мин / обычная / макс цена, разброс, тренд, и кто почём покупает
    (отклонение каждого сотрудника от обычной цены).
- **Журнал** — каждое действие и каждое изменение «было → стало», входы в систему с IP. Записи нельзя удалить или изменить
  (запрещено на уровне базы данных).
- **Команда** — добавить сотрудника (выдаётся временный пароль), отключить доступ, сбросить пароль.
- **Настройки** — окно правки (по умолчанию 2 ч), пороги проверок, объекты, категории, единицы.

## Безопасность

- Сотрудник не может открыть раздел руководителя, чужие заявки, доходы и файлы — проверяется на сервере в каждом запросе.
- Пароли — scrypt с солью; временный пароль нужно сменить при первом входе; после 5 неверных попыток — блок на 15 минут.
- Сессия в HttpOnly-cookie `SameSite=Strict`, в базе хранится только хеш токена; смена пароля закрывает остальные сеансы.
- Защита от подделки запросов, строгая Content-Security-Policy, запрет встраивания в чужие сайты.
- Файлы проверяются по содержимому (только JPG/PNG/WEBP/HEIC/PDF до 10 МБ), выдаются только тем, кому положено.
- Ничего не удаляется: заявки отменяются, файлы открепляются, сотрудники отключаются — история остаётся.

## Распознавание чеков ИИ (необязательно)

Если на сервере задан `ANTHROPIC_API_KEY`, у каждого чека появляется кнопка **«Распознать ИИ»**:
Claude читает позиции и итог, сотрудник одной кнопкой подставляет цены в отчёт, а руководитель видит расхождение,
если сумма в отчёте не совпадает с чеком. Без ключа всё остальное работает как обычно.

## Запуск

Нужен Node.js 22.13+ (используется встроенный `node:sqlite`, других зависимостей нет).

```bash
npm install
```

```bash
HEAD_LOGIN=boss HEAD_PASSWORD='Пароль123' npm start
```

Откройте http://localhost:3000. Если `HEAD_PASSWORD` не задан, временный пароль руководителя печатается в консоли при первом запуске.

Посмотреть на демо-данных (вымышленные сотрудники и 5 месяцев закупок; входы `head`, `engineer`, `master`, `welder`, пароль `demo12345`):

```bash
npm run reset && DEMO=1 npm start
```

```bash
npm test
```

### Переменные окружения

| Переменная | Что делает |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `DATA_DIR` | где хранить базу и файлы (по умолчанию `./data`) |
| `HEAD_LOGIN`, `HEAD_PASSWORD`, `HEAD_NAME` | первый руководитель (создаётся при первом запуске) |
| `COOKIE_SECURE=1` | для работы по HTTPS |
| `TRUST_PROXY=1` | за прокси (Render и т. п.) — брать IP из `X-Forwarded-For` |
| `CURRENCY` | знак валюты (по умолчанию ₴) |
| `ANTHROPIC_API_KEY` | включает распознавание чеков |
| `AI_MODEL` | модель для чеков (по умолчанию `claude-opus-5-5`) |

## Открыть для коллег

### Сразу, со своего Mac (временная ссылка)

Двойной клик по `start-mac.command` (или в Терминале `npm run share`). Скрипт установит всё нужное,
создаст пароль руководителя (сохранится в `.env.local`) и покажет ссылку вида `https://xxxx.trycloudflare.com` —
её можно отправить кому угодно, откроется с телефона и ноутбука.
Работает, пока открыто окно Терминала и Mac не спит; при каждом запуске ссылка новая. Данные хранятся на этом Mac в папке `data/`.

### Постоянно (хостинг Render.com)

1. https://dashboard.render.com → войти через GitHub.
2. **New → Blueprint** → репозиторий `dan_s` → ветка с этим кодом → **Connect**.
3. Ввести `HEAD_LOGIN` и `HEAD_PASSWORD` (вход руководителя), при желании `ANTHROPIC_API_KEY`.
4. **Apply** — через 2–3 минуты система доступна по ссылке `https://bh-uchet-xxxx.onrender.com` 24/7.

Нужен тариф Starter с диском (~7 $/мес): база и чеки хранятся в `/var/data`. На бесплатном тарифе без диска данные пропадают.

## Устройство

```
server/index.js      HTTP-сервер, маршруты, права доступа
server/logic.js      заявки, отчёты, окно правки, корректировки, доходы, файлы, проверки
server/analytics.js  аналитика, контроль цен, подотчёт
server/auth.js       пароли, сессии, защита от подбора
server/db.js         схема SQLite, журнал (только добавление), настройки
server/ai.js         распознавание чеков (Claude)
server/demo.js       демо-данные
scripts/share.js     временная публичная ссылка (Cloudflare Tunnel)
start-mac.command    запуск двойным кликом на Mac
public/              интерфейс (без фреймворков): app.js, app.css, icons.js
tests/               сквозной тест всего процесса и защиты
```
